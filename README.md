# 40 Kunlik Poklanish (40 Days of Purification)

A comprehensive 120-day spiritual transformation program designed for inner growth, healing, and renewal. This project provides a structured three-stage journey toward forgiveness, inner peace, and personal prosperity.

## Project Overview

**40 Kunlik Poklanish** is a web-based platform that guides users through a spiritual journey. It features an interactive UI with animated sections, mentoring videos, and specialized pricing modules for different program stages.

### Key Features

- **Three-Stage Journey**: Detailed modules for "Purification," "Recovery," and "Elevation."
- **Interactive Experience**: Built with AOS (Animate On Scroll) for engaging content delivery.
- **Embedded Mentoring**: Direct access to psychological sessions and guidance.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Modern Tech Stack**: HTML5, Vanilla CSS (with premium tokens), and lightweight JavaScript.

## Technical Details

- **Frontend**: Standard Web Technologies (HTML, CSS, JS).
- **Animations**: [AOS.js](https://michalsnik.github.io/aos/) for scroll animations.
- **Styles**: Custom design system with a focus on premium aesthetics (gold gradients, serif typography).
- **Architecture**: Modular script injection for dynamic sections (offers, footer, mentoring).
